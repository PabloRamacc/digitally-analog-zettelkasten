→ 21/3a3e Man kann auch so formulieren: In einem determinierten System sind präzise Wiederherstellungsmechanismen konstruierbar, die bestimmte Arten von Umweltveränderungen, von denen das System an sich abhängt, kompensieren. Umwelt und Mechanismus werden daher als in gewissen Grenzen variabel gedacht, in Grenzen, die durch das Problem des Systembestandes gezogen sind. Insofern spielt der Aequivalenzgedanke hier eine Rolle. Vgl. auch → 21/6b2 ; → 21/3,3e - → 21/3,3f .
Ein determiniertes System ist gegeben, wenn auf jede, an sich "störende" Umweltänderung eine und __nur eine__ "richtige", d.h. das System erhaltende Kompensation des Mechanismus möglich ist – die Kompensation kann natürlich aus einer Reihe von Schritten, aus Änderungen verschiedener Variablen zugleich oder nacheinander bestehen. → 21/3a3e7
