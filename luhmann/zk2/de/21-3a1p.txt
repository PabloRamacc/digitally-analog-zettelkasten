→ 21/3a1 Versuch einer allgemeinen Theorie der Bestandsvoraussetzungen eines jeden sozialen Systems → 21/3a1p(R)
Ausgangspunkt sind zwei Annahmen: 1.) dass das System nicht universal ist, also eine Umwelt hat. Das folgt aus dem Identitätsbegriff.
2.) dass der Bestand des Systems in der Stabilität von Erwartungen (bes Verhaltenserwartungen) besteht; → 21/3a1pe das folgt aus dem Begriff der Interaction (Durkheim). → 21/3a1pa
Diese beiden Annahmen zusammen besagen, dass der Bestand einer stabilen Erwartungsordnung und damit einer Sozialordnung schlechthin problematisch ist. → 21/3a1pb
Erwartungen können nun in verschiedenen Richtungen → 21/3a1pc problematisch werden, und zwar → 21/3a1pf ; → 21/3a1pg 1.) durch mangelhafte Erfüllung → 21/3a1pC ;
2.) durch fehlenden Konsens → 21/3a1pD ;
3.) durch Inkonsistenz ihres sachlichen Zusammenhanges → 21/3a1pA ; → 21/3a1pB ; → 21/3a1pE .
