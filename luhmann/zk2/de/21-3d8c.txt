Die Theorie der Beziehungen zwischen Systemen gibt den allgemeinen Rahmen für eine __funktionale Theorie des Konfliktes__. → 21/3d8c(R) ; → 21/3d8ca ; → 21/3d8cb ; → 21/3d8cd ; → 21/3d8cf ; → 21/3d8cg ; → 21/3d8ch ; → 21/3d8ci ; → 21/3d8cj
Ein Konflikt zwischen Systemen liegt immer dann vor, wenn eine positiv-funktionale Leistung für ein System in Anspruch genommen wird und dysfunktionale Konsequenzen für ein anderes System hat. Die Konfliktstheorie entspricht mithin dem Problem der dysfunktionalen Konsequenzen, angewandt auf den Fall einer Mehrheit von Systemen. → 21/3d8ce
Ausserdem muss mit Aubert 1965, S. 84 → B1496 gefordert werden, dass die Systeme ihrem antagonistischen Verhältnis in irgendeiner Form __Ausdruck__ geben (Konfliktsbewusstsein); vgl. auch → 21/3d8c9 .
