In allen Leistungsbeziehungen besteht auf der Empfänger-Seite eine __Input-Grenze__. An dieser Grenze wird durch die Kriterien des aufnehmenden Systems reduziert.
Es muss der Input so selektiert bzw. konstituiert werden, eine solche Sinngebung erhalten, dass er eine funktionsentsprechende Anschlussverarbeitung ermöglicht. Die allgemeine Form, in der das geschieht, wird im Begriff der __Gleichheit__ ( → 7/67 ) generalisiert.
