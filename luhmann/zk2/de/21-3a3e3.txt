S. 296f. → B258: "Such a hypothesis would be to the effect that within a specified range C of circumstances, a given system s (or: any system of a certain kind S, of which s is an instance) is self-regulating relative to a specified [S. 297] range R of states; i.e., after a disturbance which moves s into a state outside R, but which does not shift the internal and external circumstances of s out of the specified range C, the system s will return to a state in R. A system satisfying a hypothesis of this kind might be called __self-regulating with respect to R__."
