__Zeitliche Generalisierung von Erwartungen__ → 21/3a1pc6(R)
Vgl. auch → 23/3d ; → 54/2c ; → 54/2h ; → 21/3d8c5d ; → 31/3c11 .
Jede Erwartung impliziert gewisse zeitliche Vorstellung über den Zeitpunkt oder Zeitraum, in dem das Erwartete geschieht. Die Erwartung kann in dieser Hinsicht generalisiert sein, d.h. sie kann einen spezifischen Zeitpunkt fixieren. Wenn das Ereignis in diesem Zeitpunkt __nicht__ eintritt, ist die Erwartung enttäuscht. Ein späteres Eintreffen ist ein anderes Ereignis, bezieht sich auf andere Erwartungen. So z.B. bei einem Rendezvous. Oder sie kann eine mehr oder weniger grosse Zeitspanne offen lassen, in dem das Ereignis passieren kann. Die Frage kann jedoch nicht völlig offen bleiben. Man kann bezüglich der Erwartung unsicher sein, __ob überhaupt__. Aber man kann nicht etwas mit Bestimmtheit ohne jede Zeitvorstellung erwarten.
